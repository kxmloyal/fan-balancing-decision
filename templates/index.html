最优转速选择方法（综合评估）:

采用三级评估模型确定最优转速的具体计算方法与步骤如下：

1. 指标归一化处理：
    - 针对每个面（P1面、P2面、ST面）分别独立计算IQR（四分位距）和变异系数（CV）
    - 对计算得到的IQR值和CV值进行归一化处理，计算公式为：得分 = 1 / (1 + 指标值)

2. 面内综合得分计算：
    - 对每个面的IQR得分和CV得分进行加权综合计算
    - 计算公式：面得分 = 0.5 × IQR得分 + 0.5 × CV得分

3. 面间综合总得分计算：
    - 根据不同面的重要性权重进行加权综合计算
    - 各面权重分配：P1面权重40%，P2面权重40%，ST面权重20%
    - 计算公式：总得分 = 0.4 × P1面得分 + 0.4 × P2面得分 + 0.2 × ST面得分

4. 最优转速选择：
    - 对所有候选转速的总得分进行降序排序
    - 排序后得分最高的转速确定为最优转速

使用帮助与操作指南

  1. 在首页输入扇叶型号
  2. 上传P1/P2/ST面数据文件（至少上传一个）
  3. 点击"开始分析"按钮
  4. 查看统计结果和图表
  5. 根据需要切换不同图表类型
  6. 导出HTML或PDF报告

文件格式要求：
  • 支持 CSV/XLSX/XLS 格式
  • 第一行为转速列表（如"3000rpm","4000rpm"等）
  • 第2-31行最多30组样本数据
数据准备注意事项：
  • 确保数据格式正确，避免空行或特殊字符
  • 转速单位保持一致（建议使用rpm）
  • 每组转速下的数据样本数量尽量保持一致

系统采用三级评估模型确定最优转速：

  1. 指标归一化处理：针对每个面分别计算IQR（四分位距）和变异系数（CV），并进行归一化处理。
  2. 面内综合得分计算：对每个面的IQR得分和CV得分进行加权综合计算，权重各为50%。
  3. 面间综合总得分计算：根据不同面的重要性权重进行加权综合计算，P1面权重40%，P2面权重40%，ST面权重20%。
  4. 最优转速选择：按总得分降序排序，选择得分最高的转速作为最优转速。
