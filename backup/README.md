# 扇叶平衡补土转速评估工具

## 项目简介

扇叶平衡补土转速评估工具是一个专门用于分析扇叶平衡数据并评估最优转速选择的Web应用程序。该工具支持P1/P2/ST三面数据分析，具备转速匹配、统计分析、图表生成和报告导出等功能，帮助用户快速评估扇叶在不同转速下的平衡性能，从而选择最优的补土转速。

## 技术架构

### 核心技术栈

- **后端框架**：Flask 2.0+
- **前端框架**：Bootstrap 5.0+
- **数据处理**：Pandas
- **数据可视化**：ECharts + ECharts-Stat
- **数据库**：SQLite（用于结果存储和管理）
- **部署方案**：Gunicorn/uWSGI + Nginx

## 核心功能模块

### 1. 数据处理模块

**职责**：处理用户上传的数据文件，解析P1/P2/ST三面数据，进行数据验证和对齐。

**核心功能**：
- 多格式文件解析（CSV/XLSX/XLS/JSON/XML/TXT）
- 转速匹配与对齐（当P1和P2面转速不一致时）
- 数据质量验证（缺失值处理、异常值检测）
- 数据标准化处理
- 增强的错误处理和异常捕获

**关键文件**：`data_processing.py`、`exceptions.py`

### 2. 统计分析模块

**职责**：对处理后的数据进行统计分析，计算各项指标，评估最优转速。

**核心功能**：
- 基本统计量计算（平均值、中位数、标准差、IQR、变异系数）
- 最优转速评估（基于加权评分法）
- 数据高亮显示（最优转速和最小IQR）
- 统计报告生成

**关键文件**：`statistics.py`

### 3. 图表生成模块

**职责**：生成多种类型的图表，可视化展示数据分布和趋势。

**核心功能**：
- 支持10种图表类型：箱线图、小提琴图、散点图、趋势图、热力图、直方图、3D散点图、雷达图、气泡图、平行坐标图
- 图表缓存机制（提高性能）
- 响应式图表设计
- 图表交互功能
- 提取重复代码为可重用通用方法
- 基于ECharts和ECharts-Stat的专业统计图表

**关键文件**：`chart_generation.py`、`static/js/charts.js`、`static/js/upload.js`

### 4. Web应用模块

**职责**：提供用户界面，处理HTTP请求，展示分析结果。

**核心功能**：
- 文件上传与管理，支持进度条自动折叠
- 结果展示与导航
- 图表交互式查看
- 报告导出功能
- 增强的错误处理和异常捕获
- 蓝印架构，模块化路由管理

**关键文件**：`app.py`、`blueprints/`、`templates/`、`static/`

### 5. 数据库连接模块

**职责**：管理数据库连接，提供连接缓存和池化功能。

**核心功能**：
- 数据库连接缓存和池化
- 连接状态验证
- 异常处理和重试机制
- 多数据库支持

**关键文件**：`database_connections.py`

## 部署配置

### 配置文件说明

1. **config.py** - 应用基本配置
   - SECRET_KEY: Flask密钥
   - SESSION_TYPE: 会话存储类型
   - UPLOAD_FOLDER: 上传文件存储路径
   - OUTPUT_FOLDER: 输出文件存储路径
   - MAX_CONTENT_LENGTH: 最大上传文件大小
   - ALLOWED_EXTENSIONS: 允许上传的文件扩展名

2. **gunicorn_conf.py** - Gunicorn部署配置
   - workers: 进程数
   - threads: 线程数
   - bind: 监听地址和端口
   - 日志配置等

3. **uwsgi.ini** - uWSGI部署配置
   - processes: 进程数
   - threads: 线程数
   - http: 监听地址和端口
   - 日志配置等

### 宝塔面板部署

项目支持在宝塔面板中部署，使用Nginx反向代理转发请求至1322端口，并通过Supervisor管理Gunicorn进程。

## 使用指南

### 1. 数据准备

- 准备P1/P2/ST面数据文件，支持CSV/XLSX/XLS/JSON/XML/TXT格式
- 文件格式要求：
  - 第一行为转速列表（如"3000rpm","4000rpm"等）
  - 第2-31行最多30组样本数据

### 2. 数据上传与分析

1. 访问应用主页（http://localhost:1322）
2. 输入扇叶型号
3. 上传P1/P2/ST面数据文件（至少上传一个）
4. 点击"分析"按钮，系统自动进行数据分析
5. 查看统计结果和图表

### 3. 转速匹配（当P1和P2面转速不一致时）

1. 系统自动检测转速不一致情况
2. 进入转速匹配页面，查看默认匹配建议
3. 手动调整匹配关系（如果需要）
4. 点击"确认匹配"按钮，继续分析

### 4. 结果查看与导出

1. 在结果页面查看统计表格和图表
2. 点击图表类型按钮切换不同图表
3. 点击图表查看大图
4. 点击"导出CSV"按钮导出统计数据
5. 点击"查看HTML"按钮查看完整HTML报告

## 最优转速评估算法

采用三级评估模型确定最优转速：

1. **指标归一化处理**：
   - 单个指标得分 = 1 / (1 + 指标值)
   - 指标值越小，得分越高

2. **面内综合得分计算**：
   - 面得分 = 0.5 × IQR得分 + 0.5 × CV得分

3. **面间综合总得分计算**：
   - 总得分 = 0.4 × P1面得分 + 0.4 × P2面得分 + 0.2 × ST面得分

4. **最优转速选择**：
   - 按总得分降序排序，选择得分最高的转速
